## Skills derived from oh-my-claudecode

The following skills are copied from
[oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode) by
Yeachan Heo, under MIT License:

- `ralph` — self-loop until task completion
- `plan` — strategic planning entrypoint
- `deep-interview` — Socratic requirements extraction
- `deep-dive` — trace + interview pipeline
- `learner` — extract a learned skill from a conversation
- `skillify` — turn a repeatable workflow into a reusable skill
- `sciomc` — parallel scientist-agent analysis
- `autoresearch` — stateful single-mission improvement loop
- `ralplan` — consensus planning gate
- `ai-slop-cleaner` — regression-safe AI-code cleanup

- `release` — generic release-flow assistant
