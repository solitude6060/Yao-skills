# 對話背景與交接管理

英文 [SKILL.md](SKILL.md) 是執行規範。適用於 context（模型收到的對話背景）
超過約十萬 token（文字計量單位）、切換無關任務、準備長時間流程、費用升高，
或使用者明確要求壓縮、清理或交接。

1. 英文成本表使用示意假設：每個快取輸入 token 為 0.1 單位、新輸入為 1 單位、
   輸出為 5 單位；每回合另有一千個新輸入及三千個輸出 token。總量為快取輸入
   乘 0.1，加一千及一萬五千。使用前換成供應商實際定價與快取行為；表格未提供
   任何服務的實測結果。快取期限與壓縮效果均依執行環境確認。
2. 八萬以下通常繼續；八萬至十五萬且仍在同一任務時，使用 `/compact` 加聚焦
   提示；任務交界或超過十五萬，先保存交接再 `/clear`。優先寫專案 `handover.md`，
   再考慮 `docs/HANDOVER_<branch>.md` 或 OMC 管理的 `.omc/notepad.md`。
   交接範本在英文檔案，需保留目標、進度、檔案、待決事項及接續指令。
3. 明確授權的長時間流程使用新工作階段，定期將進度寫到持久位置並從檔案恢復。
   只有獲得授權或符合明確停止條件時才停止、重啟；不因時間經過而自動終止。
4. 子代理模型依專案指引指定的路由政策；未指定時使用已存在的
   `docs/MODEL_ROUTING.md`。工作方式由 `workflow-routing` 協助選擇。
   子代理本身與摘要均有用量，先合併可直接完成的相關查詢。
5. 不在測試失敗到修正通過的中間清理背景，不在交接落檔前清空對話。
