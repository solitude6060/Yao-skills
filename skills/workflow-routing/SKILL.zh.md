# 工作流程選擇

英文 [SKILL.md](SKILL.md) 是執行規範。先讀專案在 `AGENTS.md` 或 `CLAUDE.md`
指定的模型路由政策；未指定時，使用已存在的 `docs/MODEL_ROUTING.md`。
規劃或委派前讀專案指定的任務指引，或已存在的 `docs/TASK_GUIDANCE.md`；沒有
這份選用文件時，沿用專案指示及本技能。本技能不內附模型表。

1. 先區分工作：Coding（軟體產物）或 Research（知識產物）；混合任務以承擔
   主要風險的產物判斷。
2. 依不確定性、影響範圍、可恢復性、安全、架構及驗證成本，從 Low（低難度）
   到 Extreme（極高難度）分類。檔案數及模型可用性不直接決定難度。
3. 委派前說明分類、工具、模型、推理強度及可修改路徑。保留使用者選定的主代理；
   小範圍工作可由主代理完成。沒有路由政策時，可繼續授權範圍內的直接工作，
   只暫停缺少必要設定的委派或審查。
4. 選擇 Direct（直接完成）、Planned implementation（依計畫實作）、
   Split authority（計畫與實作由不同模型負責），或 Research decision
   （依研究政策指派分析與決策者）。重要結果由符合工作難度的獨立代理驗證。
5. 程式及影響實驗有效性的文件依審查要求使用 `triple-review`，採專案設定的
   獨立審查者。一般文件使用驗證工具；設定及版本鎖定檔依實際風險判斷。
6. 子代理不得再委派。工具、模型、推理強度、授權及備援依專案政策；備援維持
   同一工作類別與難度，記錄原選擇、失敗原因及實際替代者。
7. 平行修改的路徑不得重疊；worktree（獨立工作目錄）管理使用 `worktree-hygiene`。
   持久產物不得放在 `/tmp`。

說明工作分類、流程、模型、推理強度與是否需要獨立審查，再開始已授權步驟。
沒有當次任務授權，不發布、核准或合併。
