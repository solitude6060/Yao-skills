# 同期作品

英文版 [concurrent-work.md](concurrent-work.md) 為執行規範。

與本研究重疊的 preprint（預印本）可以讓貢獻更清楚，也可能在無意間改變研究方向。規則是：比較它，把它當作對照與評估上的提醒來引用，研究問題則維持由專案自己的決策紀錄管理。

## 何時檢查

- 每個里程碑，以及摘要截止日與全文截止日之前各一次。
- 擁有者、指導教授或審稿人點名一篇新論文時。
- 選定後續題目時（最接近與同期的作品是 `research-ideation` 的可行性檢查之一）。

用本研究的核心詞彙，以及方法所屬模型類別曾用來發表的每一個名稱，搜尋預印本平台與會議網頁；記錄查詢字串與日期。

## 比較表

| 欄位 | 內容 |
|---|---|
| 作品 | 已達引用三步檢查第 2 或第 3 步的引用 |
| 任務與情境 | 預測什麼、用哪些輸入、在哪種切分下 |
| 資訊取用 | 方法在推論時讀什麼、用什麼訓練；目標是否被放進候選集合 |
| 候選建構與協定 | 全排序、抽樣候選（如何抽樣）、先檢索再重排 |
| 主張 | 它的主要主張，附位置的引文 |
| 與本研究的重疊 | 相同問題、相同訊號、相同模型類別、相同資料 |
| 差異 | 本研究做了而它沒做的，以及反過來 |
| 對本研究的影響 | 無；新的基線；新的對照；需要揭露；透過決策紀錄提出的範圍變更 |

## 規則

- 同期作品絕不重新定義研究問題。提出的變更連同證據寫進決策紀錄，由擁有者決定。
- 它的協定與本研究的差異會改變分數時（例如把目標放進候選集合），把它當作評估上的提醒；主張依賴這一點時，量測其影響。
- 有重疊之處，在相關研究章節用一段文字寫明差異。
- 引用它論文中的結果時，連同協定一起引用；不同協定下的數字不放在同一個比較欄位。

通用案例：一篇早期的同期 preprint，幾乎讓本研究的問題轉向它自己的重排情境，直到擁有者要求只把它當作對照；另一例是兩篇在投稿後出現的 preprint 被整理成比較表，這張表也列出了審稿人可能提出的問題。

## 審稿人的問題與 rebuttal 的銜接

對每一篇重疊的作品，寫下審稿人可能提出的問題（「這和 X 有什麼不同？」「為什麼不和 X 比較？」），並為每個問題寫出回答它的證據：既有的表格、一句話，或一項備用分析。能在 rebuttal（作者回覆）期限內完成的備用分析，在 `paper-argument` 的審查與回覆參考檔中規劃（[review-and-rebuttal.zh.md](../../paper-argument/references/review-and-rebuttal.zh.md)）。
