# 正文與附錄

英文版 [body-appendix.md](body-appendix.md) 為執行規範。

許多會議限制內容頁數，並允許參考文獻與附錄放在其後。例如 ACM Web Conference 2027 的徵稿說明：內容八頁，單一 PDF 總共至多十二頁，審稿人不必閱讀第八頁之後的內容。投稿前要查目標會議最新的徵稿說明：內容頁數、是否接受獨立補充檔、附錄是否計入總頁數。

## 判斷表

| 內容 | 正文 | 附錄 |
|---|---|---|
| 問題、研究問句、貢獻 | 是 | 否 |
| 方法：公式與每個元件的設計理由 | 是 | 推導、實作細節 |
| 資料集：名稱、規模、以一段或一張小表說明協議 | 是 | 前處理、篩選條件、表中以外的統計 |
| 基線（baseline：比較對象）：清單，每項一行說明與來源 | 是 | 設定、搜尋空間、版本、硬體 |
| 主要比較表 | 是 | 各使用者群或次要指標的版本 |
| 主要主張的顯著性或區間 | 標記或差值欄 | 完整區間表 |
| 回答每個核心問題的分析 | 各一張表或一張圖 | 其他變體、敏感度掃描 |
| 穩健性（robustness：換一種設定重做，確認結論是否維持）與協議敏感度 | 每項檢查一句話加關鍵數字 | 完整表格 |
| 成本與延遲 | 一張圖或一張精簡表 | 含所有欄位的完整成本表 |
| 案例分析 | 支持核心主張時放一個精簡例子 | 其他案例 |
| 限制 | 指明主張及其適用範圍 | — |
| prompt、模板、網格、模型版本、倫理細節 | 否 | 是 |

## 檢驗

1. **移除檢驗。** 拿掉某個段落或圖表後，若正文的每項主張仍有證據支持，就移到附錄。
2. **自足檢驗。** 只讀正文時，每項主張都有證據、每個符號都有定義、每個關鍵但書都看得到。
3. **引用檢驗。** 每個附錄章節在正文中被引用一次，位置在讀者會想查閱之處。
4. **單一 PDF 檢驗。** 會議只收一份 PDF 時，不另附補充檔；併入附錄並維持在總頁數內，或刪除。
