# 寫作規則與範例

英文版 [writing-rules.md](writing-rules.md) 為執行規範。

規則整理自作者對整篇論文草稿的修正，以及指導教授的意見。每條規則都註明它防止的問題。作者每提出一條新規則，就在同一次變更把它加到這裡。

## 結構

| 規則 | 防止的問題 |
|---|---|
| 引言提出一個主問題與兩三個子問題；結論依相同的順序與用詞回答。 | 論文只報告結果，卻沒說這些結果回答什麼。 |
| 每一節開頭寫它服務的問題，結尾寫答案：一句粗體小結，或段落的最後一句。 | 讀起來像數字清單的章節。 |
| 每個論點依序寫理由、描述、分析、結論。 | 只描述、不分析（「只描述，從不下結論」）。 |
| 摘要與引言最多列兩三個亮點；次要發現成為亮點底下的證據。 | 幾個分量相當的主張互相稀釋。 |
| 摘要明確列出貢獻，每項附一個數字。 | 摘要只敘述方法，讓讀者自己猜貢獻。 |
| 貢獻與章節一對一對應，並寫明對應關係。 | 沒有任何章節支持的貢獻。 |

## 句子

| 規則 | 修正範例 |
|---|---|
| 短句；一句一個主張。 | 一句同時帶結果、條件與但書時，拆成兩三句。 |
| 少用括號。括號內的細節移到表格、註腳或附錄。 | 「（前 1,000 位使用者、99 個抽樣負例、seed 0）」寫在表格標題說明一次即可，不必每句都寫。 |
| 不用破折號連接句子。數字範圍的破折號可以用。 | 把「X——而 Y——Z」改成兩句。 |
| 使用標準術語；已有名稱的概念不另造說法。 | 用「截斷」（truncation），不用「超長度」。 |
| 技術敘述不用比喻與擬人。 | 寫「信賴區間與基線重疊」，不寫「誤差線仍蓋住基線」。 |
| 不用「是 X，不是 Y」的對比句；直接陳述觀察。 | 「三項檢查結果均落在雜訊範圍內。」 |
| 不用自誇的形容詞（remarkable、superior、novel paradigm）。數字支持時，可以明確主張。 | 寫「超過每個訓練式基線至少 5%」，不寫「驚人地優於」。 |
| 原因未查明時，寫「原因未查明」，後文不補推測性的原因。 | — |
| 學術與專業語體，不寫成工程紀錄，也不生硬。 | 正文移除執行編號、檔名與日期。 |

## 數字

| 規則 | 防止的問題 |
|---|---|
| 全文一種數字格式：絕對差值，括號內寫相對變化，例如 +0.030 (+6.0%)。摘要可以只用相對變化。 | 讀者要自己在不同格式之間換算。 |
| 內文只引用承載論點的一兩個數字，其餘留在表中。 | 機械式逐格複誦。 |
| 每個指標的小數位數固定（多數推薦系統論文對 NDCG 與 HR 用三位）；百分比由未四捨五入的值計算。 | 內文與表格的四捨五入不一致。 |
| 區間包含零的比較，寫成「相當」或「在…範圍內」並附區間。 | 對不顯著的差值寫「優於」。 |
| 內文中的每個數字，都存在於表、圖或附錄，也存在於結果檔。 | 無法追溯來源的孤立數字。 |

## 主張與證據

| 規則 | 防止的問題 |
|---|---|
| 資料集、模型或使用者群改變時，重新驗證每個量化主張（至多、從未、所有、每個、兩者皆）。 | 在舊資料成立、在新資料失效的界限。 |
| 關鍵但書連同數字寫在正文，完整證據放附錄。 | 只有讀附錄的人才看得到的但書。 |
| 揭露重複執行之間的任何挑選；較好的做法是不依測試分數在多次執行中挑選。 | 以測試集挑選的結果被當成成果。 |
| 看過結果之後才更換資料集時，寫出獨立於結果的理由（例如時間戳記記錄評分輸入的時間，無法代表消費發生的時間），或把該資料集的結果留在附錄。 | 「資料集是事後挑選」的質疑。 |
| 沒有公開權重的託管模型要標明；主要主張盡量建立在可重現的模型上。 | 針對主要結果的可重現性質疑。 |

## 內文中的圖表

| 規則 | 防止的問題 |
|---|---|
| 用小表或小圖取代列舉設定或數值的段落。 | 密集的列舉式文字。 |
| 每個圖表在出現之前先在內文引用，並說明要看什麼。 | 讀者得自行解讀的圖表。 |
| 草稿中執行中或待補的格子保持空白，不加說明；不編造空白格的原因。 | 標題說明中未經查證的陳述。 |

## 最後檢查

1. 搜尋原始檔中每個量化用語與每個資料集名稱，逐一對照結果檔重新驗證。
2. 搜尋破折號、被禁用的形容詞、比喻與「不是 X，而是 Y」的句型。
3. 編譯後逐頁檢查：超出欄寬的行、圖表位置、表格寬度、圖的字體。
4. 兩次獨立的語言檢查（不同模型家族或不同的人），最後由作者確認。
