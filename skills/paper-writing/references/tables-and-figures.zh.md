# 表格與圖

英文版 [tables-and-figures.md](tables-and-figures.md) 為執行規範。

規則整理自作者的修正，以及經典推薦系統論文（SASRec、LightGCN、EASE 風格的表格）的做法。修改產生表格的程式，不直接修改產出的檔案。

## 表格

| 規則 | 說明 |
|---|---|
| 一張表一個問題 | 一張表回答兩個問題時，拆開，或把其中一半移到附錄。 |
| 比較放在相鄰的儲存格 | 提出的方法放在最強基線旁邊，或加一欄差值。 |
| 一個數字只出現在一處 | 兩張表共用列（方法）或欄（資料集、指標）時，合併，或刪除重複的區塊。 |
| 主要指標放最前面 | 正文篇幅不足時，次要指標（MRR、其他 K 值的 HR）移到附錄。 |
| 簡短的 caption（圖表標題說明） | 第一句寫這張表呈現什麼；之後最多兩個短句說明標記與縮寫。不寫成大段附註。 |
| 經典版面 | booktabs（LaTeX 的表格套件）的上、中、下橫線，不用垂直線，不加底色，caption 放在表上方。 |
| 數字 | 每個指標的小數位數固定，並對齊小數點；最佳值用粗體；次佳值只在比較需要時加底線。 |
| 分組 | 方法類別之間用中線分隔，並加簡短的組名。 |
| 順序一致 | 每張表與每張圖的資料集順序、方法順序相同。 |
| 標記 | 每個符號都在 caption 說明；標記的種類愈少愈好。 |
| 寬度 | 優先使用單欄表格；跨欄的寬表必須承載主要比較。 |

## 合併方式

| 情況 | 合併方式 |
|---|---|
| 主結果表之外，另有一張帶區間的成對差值表 | 合為一張：加上對最強基線的差值欄，或標記區間不含零的儲存格；完整區間表放附錄。 |
| 每個穩健性變體各有一張表（不同負例、不同時間錨點） | 一張表，變體為欄組，只保留主張需要的方法列；或正文每個變體一句話，表放附錄。 |
| 消融（ablation）表與另一張「單獨使用某元件」表 | 合為兩個區塊的一張表，或正文只留移除區塊。 |
| 成本表與成本圖呈現相同數字 | 圖放正文（品質對成本），表放附錄。 |
| 設定、網格、prompt | 只放附錄。 |
| 同一張表在不同使用者群重複（開發群與確認群） | 正文放確認群或全體；其他群放附錄。 |
| 低於既定門檻的小幅變動 | 合成一行附註，不逐列呈現。 |

## 圖

| 規則 | 說明 |
|---|---|
| 向量格式 | PDF 或 PGF（LaTeX 的繪圖格式）；縮放後的字體大小與正文一致。 |
| 配色 | 全文使用同一組色盲友善的配色；每個序列另加第二種編碼（標記形狀或線型）。 |
| 簡潔的座標軸 | 淺色格線、圖內不放標題（由 caption 負責）、圖例放在圖內或共用。 |
| Caption | 放在圖下方；第一句寫發現。 |
| 總覽圖 | 標籤與內文使用的章節、模組名稱一致。 |
| 一張圖一個訊息 | 多個子圖仍回答同一個問題；否則拆開，或把子圖移到附錄。 |
