# 繁體中文台灣用語檢視

英文 frontmatter 的 [SKILL.md](SKILL.md) 是執行規範，內文本身即為繁體中文。

用在產出任何繁中內容（chat、README、計畫檔、審查文件、註解）送出之前，或使用者說
「繁中檢視」「tc review」「台灣用語檢查」的時候。

1. 訊息保留與文字通順同時最大化；英文技術字詞原樣保留。
2. 簡中零容忍：一處滲漏代表整段要重讀，不只改那個字。字形層（执行→執行）容易抓；
   構詞層（軟件、視頻、內存、默認、技術棧、信息、服務器）更常見。
3. 中英夾雜只留技術名詞與圈內通用縮寫；英文普通詞彙插在中文句子裡要改掉。
4. 不用口語壓縮與編輯式修飾；讀起來要像台灣工程師寫的技術文件。
5. 改寫不能刪掉限定詞、數字、路徑、指令、例外與版本限制。
6. 檢視自己的輸出直接修正後送出，不另報告；檢視他人文件列出位置與建議。
