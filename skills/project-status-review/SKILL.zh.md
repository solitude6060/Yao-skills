# 專案狀態檢視

英文 [SKILL.md](SKILL.md) 是執行規範。

用在使用者問「專案做到哪」「進度」「狀態」「有什麼 blocker」「已完成／待完成」的時候。
只讀不改，產出一份報告。

1. 平行蒐集：最近 20 筆 commit、分支、整合分支對 main 的差距；`status.md`／
   `tracker.md`／`handover.md`（專案管理紀錄）與 README；原始碼、測試、文件的數量；
   有測試或建置腳本且相依已安裝就跑一次，否則寫「未執行」與原因；lock file 年齡。
2. 依英文檔內的繁中報告範本填滿十節：標頭、里程碑、程式碼統計、已完成功能、分支表、
   技術堆疊、blocker（P0 secrets 與部署決策、P1 下個小版前、P2 之後）、版本規劃、風險、
   三項優先行動、文件與實況的落差。範本中的堆疊與 secret 名稱／狀態列要換成該專案實際內容，
   不要輸出 secret 值。
3. 每個數字都寫出來源指令或檔案；不沿用舊狀態檔的數字。
4. 結尾只問一句：要不要開始哪一項建議行動。
