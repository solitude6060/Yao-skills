# 評估以 LLM 為基礎與凍結模型的推薦器

英文版 [llm-recsys-evaluation.md](llm-recsys-evaluation.md) 為執行規範。

比較的方法中有語言模型、LLM agent，或依文字為候選評分的凍結模型時閱讀。

## 候選清單大小

- LLM 排序論文多半使用小型的抽樣候選清單：LLMRank 20 個候選
  （[Hou et al., ECIR 2024, §3](https://arxiv.org/pdf/2305.08845)）、A-LLMRec 1+19
  （[§5.1](https://arxiv.org/pdf/2404.11343)）、AgentCF 1+9
  （[§3.1](https://arxiv.org/pdf/2310.09233)）、LLM-SRec 1+99
  （[§2.2](https://arxiv.org/pdf/2502.13909)）、LLaRA 20 個候選與 HitRatio@1
  （[§5.1](https://wujcan.github.io/papers/sigir24-llara.pdf)）。
- prompt 長度、延遲與位置效應會隨 n 增加。報告巢狀集合（20 ⊂ 50 ⊂ 100）上的候選數量曲線，避免只報告單一 n。
- 要主張完整目錄上的結果，使用兩階段評估（見 `candidates-and-metrics.zh.md`）。

## 位置偏差與順序置換

- [LLMRank §3.2](https://arxiv.org/pdf/2305.08845)：LLM "suffer from position bias
  and popularity bias while ranking"；對每個候選集合以打亂的順序排序 3 次（bootstrapping），可降低位置偏差。
- 固定並記錄候選順序的 seed。檢查目標的位置在各查詢之間是否均勻。承載主要主張時，做一次置換檢查（相同查詢、打亂順序），並報告變化。

## 解析失敗與無效輸出

- 生成式排序器可能回傳候選清單以外的商品、重複項目、被截斷的清單或自由文字。解析器只定義一次，套用到每個生成式方法，並依類型計數失敗。
- 無法解析的輸出屬於方法失敗：效用為 0，留在分母，並報告筆數。因方法本身冗長而被 token 上限截斷，屬於方法失敗；伺服器錯誤屬於執行失敗，要重跑。
- 以似然或 logit 為每個候選評分的讀取式方法沒有解析失敗；要如實說明，不要把 0 當成成就來報告。

## 商品文字

- 寫明使用的文字欄位：只有標題、標題加類別、標題加描述、評論。結果會隨文字的豐富程度與長度而變。
- 檢查分數是否與描述長度或 prompt 位置相關；抽樣集合中，若目標的文字系統性地比負例短或長，長度啟發式就可能得到高於隨機的分數。
- 比較中的每個方法使用相同的文字欄位，否則把差異標示為一個條件。

## 證明方法使用個人證據的對照

| 對照 | 排除什麼 |
|---|---|
| 字詞重疊基線（歷史文字與候選文字的 BM25） | 由字詞重疊解釋的增益 |
| 類別比對規則 | 由類別連續性解釋的增益 |
| 熱門度與近期性規則 | 由商品熱門度或近期商品解釋的增益 |
| 歷史對調／錯配（把使用者 A 的歷史給使用者 B 的查詢） | 方法忽略歷史；正確歷史與對調歷史之間的大幅下降，顯示方法使用了個人證據 |
| 空白或截斷的歷史 | 對歷史長度的依賴 |
| 依目標熱門度分層 | 對熱門目標的依賴 |

報告「正確減對調」的差值，並附成對區間。

## 延遲、token 與成本

- 報告每個查詢的延遲（中位數與尾端）、輸入與輸出 token，以及每 1,000 個查詢的成本並註明價格日期。
- 每個方法使用相同的快取條件：所有方法都重用 prompt 前綴快取，或都不使用。寫明硬體、批次大小與服務堆疊。
- 一次性成本（訓練、建立索引）與每個查詢的成本分開。

## 預訓練曝露

- 凍結模型在預訓練期間，可能看過資料集的評論或商品頁面。這與訓練切分中的跨使用者未來資料不是同一個管道，任何切分都無法移除它。
- 揭露模型的訓練資料截止時間與已知來源，並與資料集的時間範圍對照。可能的話，加入模型不太可能看過的領域或時期，或在模型截止時間之後發布的資料集。

## 其他 LLM 專屬的報告項目

- API 回傳的模型識別、請求雜湊值、解碼參數，以及完整的 prompt 模板。
- 對 agent（多步驟工具使用、記憶）：每個查詢的 LLM 呼叫次數，以及記憶是否只由訓練使用者建立。
- 區分目標領域訓練（經微調的 LLM 推薦器，如 TALLRec、LLaRA、A-LLMRec、LLM-SRec）與免訓練的使用；它們屬於不同的資訊取用層級（`baselines-and-fairness.zh.md`）。
