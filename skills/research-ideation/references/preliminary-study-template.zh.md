# 初步研究計畫範本

英文版 [preliminary-study-template.md](preliminary-study-template.md) 為執行規範。

Preliminary study（初步研究）產生能為一個方向決定「繼續、調整或停止」的最小結果。它不是完整的實驗矩陣；完整矩陣在關卡通過之後，於 `experiment-planning` 建立。

## 章節

| 章節 | 內容 |
|---|---|
| 0. 與先前文件的關係 | 表格：文件、題目、關係（沿用、被取代、僅供背景） |
| 1. 問題 | 表格：附白話名稱的代號、問題、它服務的研究問題、它決定什麼 |
| 2. 共同規則 | 資訊邊界；只在驗證資料上選參；執行失敗與方法失敗的區分；逐請求的雜湊值；證據階段與 seed（隨機種子）；基線使用官方來源；輸出位置 |
| 3. 資料與使用者群 | 資料集、使用者群（cohort）與其曝光紀錄、候選建構方式、哪些內容不需新的模型呼叫就能重用 |
| 4. 階段 | 表格：階段、內容、完成條件、裝置或服務 |
| 5. 繼續或停止條件 | 表格：檢查點、條件、未達成時怎麼辦 |
| 6. 時程 | 真實日期、已知的衝突（其他截止日、rebuttal（作者回覆）期間、資源可用時段） |
| 7. 先寫的測試 | 第 1 階段之前必須通過的邊界、候選、請求與身分測試 |
| 8. 輸出與紀錄 | 每個階段一個資料夾，含 README、程式、指標檔與原始回應；紀錄寫在 status、tracker 與 handover |
| 9. 已決定與待決定 | 擁有者的決定照原文並註明日期；待決事項寫成自成一體的問題 |
| 10. 參考文獻 | 依角色分組：最接近的作品、同期作品、使用的方法、協定來源 |

## 撰寫繼續或停止條件

- 每個條件都是與一個點名的基線或對照的比較，在驗證資料上判讀，以白話寫出：「引導後的模型在兩個資料集上，都把驗證目標排得比同一組訊號的 late fusion（後期融合：各自算分再加總）更前面」。
- 不設任意的數值門檻。只有主張等價（equivalence）時才出現容許差距（margin），而且在執行前宣告。
- 測試目標在設定凍結之後只回報一次；它們從不決定關卡。
- 事先宣告的調整（若有）與條件寫在一起（「調整一次損失函數或步數，仍未通過就停止」）。看到結果之後，其他一切都不改。
- 屬於篩選（screening）的階段（一次執行、點估計或配對差）可以決定下一步；不能支持穩健性或優越性的主張。

## 範例列

| 檢查點 | 條件 | 未達成時 |
|---|---|---|
| 階段 A 之後 | 在兩個資料集的驗證目標上，調整後的輸出都勝過同一模型未調整的輸出 | 階段 A 只保留為分析 |
| 階段 B1 之後 | 新的模型類別在驗證目標上，達到它起始的強基線的準確度 | 做一次事先宣告的調整，然後停止方向 B |
| 階段 B2 之後 | 在驗證目標上，引導勝過同一組訊號的 late fusion 與特徵注入 | 記錄「此階段未達事先宣告的驗證條件」，並列出各對照的實際結果；停止方向 B |
| 決定日 | 擁有者依上面的結果選擇方向與投稿會議 | 備案清單中的下一個會議，或停止 |

通用案例：一個初步研究關卡在一個資料集上通過、在另一個資料集上未通過；依事先宣告的規則，該元件保留為分析，計畫繼續往下進行，沒有改寫關卡文字。
