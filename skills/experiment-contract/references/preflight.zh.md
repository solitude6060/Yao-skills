# 啟動前檢查

英文版 [preflight.md](preflight.md) 為執行規範。

在一批實驗、一次高成本重跑，或新模型、新資料集、新條件第一次執行之前進行。目的是：啟動的執行就是計畫描述的那個執行，而且不會在幾小時後，因為只要試跑幾個單位就能發現的原因而失敗。

## 契約欄位

啟動前把這些寫進實驗卡或計畫；卡片欄位來自 [experiment-planning](../../experiment-planning/references/experiment-card.zh.md)（固定不變項、失敗處理、證據階段）。缺任何一欄的執行還沒準備好。

| 欄位 | 內容 | 防止的失誤 |
|---|---|---|
| 研究問題 | 執行回答的研究問題，寫代號與文字 | 沒有回答任何問題的執行 |
| 使用者群 | 開發、報告與校準用的單位；先前哪些執行看過各群 | 以報告群的測試目標選參（使用者互斥協定下，以它的任何目標選參） |
| 候選 | 候選規則、大小與雜湊值 | 在不同候選集合上比較 |
| 輸入 | 每個方法讀取的欄位、歷史長度、時間邊界 | 一個方法讀到的比對手多 |
| 讀出方式 | 輸出格式、解析器、如何讀出分數或名次 | 兩個模型透過不同的讀出方式比較 |
| 證據階段 | 篩選（一次執行、點估計）或確認（測試單位上配對差的不確定性；有訓練或解碼隨機性的方法另加多個 seed（隨機種子）或重複執行，否則主張限定於一次訓練執行）；每個方法的 seed | 篩選執行被用於穩健性主張；以單位為抽樣對象的 bootstrap（重抽樣估計區間）被當成涵蓋 seed 造成的變異 |
| 選擇目標 | 在驗證資料上依什麼目標選什麼 | 另一個目標下的變體被當成主結果列 |
| 重試 | 事先宣告的重試輪數；輪與輪之間解析器不變 | 看過分數之後才決定重試 |
| 成本欄位 | 總執行時間、延遲、峰值記憶體、裝置；呼叫模型的執行另加呼叫次數、token（模型計算輸入長度的單位）與 API 費用；訓練式模型記錄每個單位的推論時間 | 無法比較的成本表 |
| 預期判讀 | 相對於點名比較對象的方向 | 事後才爭論結果 |

## 固定身分

欄位清單：[run-identity.zh.md](run-identity.zh.md)。每一批新實驗之前：

- 雲端代管模型（hosted model）：送一個探測請求，比對回傳的模型 id 與要求的是否相同；記錄服務提供者的版本字串。通用案例：一個雲端端點對某個模型名稱回覆的是另一個模型，結果混了兩個模型。
- 本地模型：記錄權重版本與檔案雜湊值，不只記模型名稱。
- 程式：對執行 import 的每個檔案計算雜湊值，包括轉接程式（adapter）、解析器與計分腳本。通用案例：一次封存（seal）只計算了主腳本的雜湊值，沒有計算一個在封存後被修改的計分腳本，產生結果的程式只好事後重建。
- 與前一批的身分比對。任何變動在說明清楚之前，都是未解決的差異。

## Smoke run（小規模試跑）

用真實資料、完整規模、精確的設定跑少數幾個單位：

- 最大的候選集合與最長的輸入，也就是記憶體峰值所在（通用案例：一個在小候選數下放得下的讀出方式，在最大候選數時記憶體不足，該批的每個單位都失敗）；
- 連接埠可用，伺服器能啟動與停止，執行程式結束時模型伺服器被釋放；
- 輸出能解析，每個輸出路徑都有寫入，成本欄位都在；
- 請求做的事與它的標籤相符（名為「只改順序」的介入只改變順序，不會例如把兩種順序的結果平均）。

在合成資料或較小規模上的 smoke run 不算數。

## 對等性

對互相比較的模型：

- 證據、組裝後的請求（rendered request）與候選清單的逐單位雜湊值，在協定說應該相同之處要相同；這三個雜湊值分開保存，不符時才能指出原因；
- 讀出方式依各模型的原始做法，除非實驗本身控制讀出方式；
- 共用同一個 tokenizer（分詞器）的模型之間，每個單位的 token 數是快速檢查；tokenizer 不同時，比對組裝後文字的雜湊值或字元數，並先檢查差距很大的單位，再判斷是否有一方拿到更多或不同的文字；
- 每個單位可見的歷史筆數相同，或差異本身是一個標明的條件。

## 重跑清單

對輸入、prompt（提示詞）、邊界、解析器或程式的每一項變動：

| 變動項目 | 讀取它的執行 | 是否重跑？ | 不重跑的理由 |
|---|---|---|---|
| | | 是／否 | |

觸及共用輸入的變動，重跑每一個讀取它的執行。沒有觸及某次執行任何輸入的變動，也要寫下理由。

## 核准

高成本的重跑，把完整規格交給擁有者（上述欄位、重跑清單、依量測吞吐量估計的成本與執行時間），確認後只啟動一次。規格還沒完整就開始的部分重跑，常常要再重跑一次。同時執行待決事項影響不到的部分。
