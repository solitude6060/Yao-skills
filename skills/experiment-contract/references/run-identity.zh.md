# 執行身分

英文版 [run-identity.md](run-identity.md) 為執行規範。

一次執行需要的最低限度來源紀錄（provenance），讓別人能說出每個數字是由哪個程式、模型與資料產生的，並能重跑。小型紀錄（這份清單、設定快照、雜湊值、彙總值）放在版本控制中；大型或私密的材料（原始回應、checkpoint（模型檢查點）、快取、紀錄檔）放在永久儲存區，並從結果表連結。

## 欄位

| 群組 | 欄位 |
|---|---|
| 執行 | 執行 id、契約或實驗卡版本、研究問題、證據階段、取自 `date` 的啟動與結束時間 |
| 來源 | 每個重用方法的上游 URL 與版本；實際 import 的檔案與其雜湊值，包括轉接程式（adapter）、解析器與計分腳本；與來源的本地差異及其授權 |
| 設定 | 完整的設定快照；哪些值是來源預設、已發表的設定或專案自行加入的 |
| 資料 | 資料集版本、前處理步驟、切分規則、事件與商品對應、資料集雜湊值 |
| 單位 | 使用者群 id、目標規則、候選規則；候選雜湊值 |
| 輸入 | 證據雜湊值、組裝後請求（rendered request）的雜湊值與候選雜湊值，三者分開保存 |
| 模型 | 要求的模型 id；雲端代管模型每個回應回傳的模型 id；服務提供者的版本字串；本地模型的權重版本與雜湊值；訓練式模型的 checkpoint id、選參階段與重新擬合（refit）階段 |
| 隨機性 | Seed（隨機種子）；是否觀察到確定性（determinism：相同輸入得到相同輸出），以及在什麼執行環境下（同一個 session、同一個裝置） |
| 環境 | 直譯器、框架與相依套件版本、裝置、驅動程式 |
| 執行過程 | 精確的指令、每個單位的嘗試次數與原因、使用的重試輪數 |
| 輸出 | 原始請求與回應的路徑（在計算任何指標之前存下）、逐單位結果檔、彙總值 |
| 成本 | 呼叫次數、token、總執行時間、延遲中位數與 p95、峰值記憶體、API 費用 |

## 不可記錄的內容

絕不儲存憑證：設定快照、紀錄檔、收據或已發布的紀錄中，不放 API key、token、密碼或 session cookie。記錄使用了哪一種憑證角色，不記它的值。離開本機的請求與紀錄檔要移除個人資料。

## 確定性

確定性要實際觀察，不能假設。沒有隨機元件的方法，在不同的伺服器 session（工作階段）或裝置之間，仍可能回傳不同的輸出。記錄觀察到的情形（「同一個 session 中送兩次，結果相同」），不記預期。通用案例：在同一個伺服器 session 中完全重複的答案，跨 session 時並不完全重複；原因未查明，身分紀錄現在會寫明 session。
