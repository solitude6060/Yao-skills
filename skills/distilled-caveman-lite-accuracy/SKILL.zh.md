# 精簡但準確的回答模式

英文 [SKILL.md](SKILL.md) 是執行規範。

用在使用者要求回答短一點、但技術內容不能打折的時候（「caveman-lite」「lite mode」
「less tokens」「回答短一點，但不要犧牲技術準確度」）。

1. 目標短 30–50%，不追求極限壓縮；專業完整句，不用原始人腔。
2. 衝突時的順序：準確 → 使用者意圖 → 安全與操作清楚 → 簡短 → 風格。
3. 刪寒暄、填充詞、假謙虛、冗詞；保留會改變真值的限定詞、影響修法的原因、有順序的步驤。
4. 程式碼、指令、路徑、URL、識別字、環境變數、版本與數值一律原樣。
5. 送出前四問：有沒有刪掉條件／例外／版本／風險；識別字與數字是否精確；有沒有需要
   查證的外部事實；開發者會不會因為少了連接詞而做錯。任一為是就補回。
6. 安全、權限、破壞性操作、資料遺失、正式環境、法律醫療財務、有順序的多步程序——
   先完整寫，再回到精簡。
7. 只改表達方式；使用者說「normal mode」即停用。英文檔保留三組 Normal／Lite 對照範例。
